# بیمه حوادث مشترکین گاز

نمونه اولیه سامانه ثبت و پیگیری پرونده خسارت حوادث گاز، با سه نقش اصلی:

1. **شرکت گاز** مشترک حادثه‌دیده را ثبت می‌کند. سامانه حساب کاربری و رمز موقت می‌سازد و پیامک می‌کند.
2. **مشترک** وارد می‌شود و اطلاعات حادثه، خسارت‌ها، عکس‌ها، مدارک و شبا را بارگذاری و پرونده را ارسال می‌کند.
3. **شرکت گاز** بررسی می‌کند، گزارش بازدید را ثبت و نقص‌ها را مورد به مورد اعلام می‌کند. پس از تکمیل، پرونده را برای بیمه‌گر می‌فرستد.
4. **بیمه‌گر** ارزیابی می‌کند، در صورت نیاز مدرک تکمیلی می‌خواهد و مبلغ را اعلام می‌کند. پس از قبول مشترک، پرداخت را ثبت می‌کند.

نیازها، گردش کار، قواعد، موارد خاص و معماری نسخه عملیاتی در [docs/DESIGN.md](docs/DESIGN.md) آمده است.

## اجرا

برنامه بدون ساخت (build) و بدون وابستگی اجرا می‌شود و فقط به یک سرور ساده HTTP نیاز دارد:

```bash
python3 -m http.server 8000
# مرورگر: http://localhost:8000
```

روی گوشی قابل نصب (PWA) است و پس از اولین بار، پوسته برنامه آفلاین هم باز می‌شود.

### حساب‌های نمایشی

| نقش | نام کاربری | رمز |
|---|---|---|
| مشترک (پرونده دارای نقص) | `1023456789` | `123456` |
| مشترک (منتظر تأیید مبلغ) | `1045678912` | `123456` |
| مشترک (ورود اول، تغییر رمز اجباری) | `1067891234` | `123456` |
| مشترک (حواله صادر شده؛ مراحل مالی) | `1024681357` | `123456` |
| کارشناس شرکت گاز | `gas` | `gas123` |
| کارشناس بیمه‌گر | `bime` | `bime123` |
| مدیر سامانه | `admin` | `admin123` |

همین حساب‌ها در صفحه ورود به‌صورت دکمه «ورود سریع» هم آمده‌اند. مدیر می‌تواند از «بازنشانی نمایشی» داده‌های نمونه را دوباره بسازد.

> نسخه فعلی همه داده‌ها را در مرورگر همان دستگاه نگه می‌دارد. برای کار واقعی بین مشترک، شرکت گاز و بیمه‌گر، به سرور نیاز است (بخش ۱۱ سند طراحی).

## اپ و سایت

همین برنامه دو نسخه دارد که داده‌شان روی هر دستگاه مشترک است:

| نسخه | نشانی | مناسب برای |
|---|---|---|
| اپ موبایل (قابل نصب) | `/` | نصب روی صفحه اصلی گوشی؛ نوار پایین و برگه‌های کشویی |
| سایت | `/site/` | کامپیوتر یا هر مرورگری که اپ در آن نصب یا باز نمی‌شود؛ منوی بالا، صفحه معرفی، موشن‌گرافی مسیر پرونده، مدارک لازم و پرسش‌ها |

برای اجرای محلی سایت: `site.html` را از همان سرور ساده باز کنید.

## نصب روی صفحه اصلی گوشی

گردش کار `.github/workflows/pages.yml` با هر push روی `main` تست‌ها را اجرا می‌کند، نسخه قابل نصب را در `dist/pwa/` می‌سازد و روی GitHub Pages منتشر می‌کند. اگر Pages خودکار فعال نشد: Settings ← Pages ← Source را روی «GitHub Actions» بگذارید.

روی گوشی نشانی سایت را در کروم باز کنید و از منوی ⋮ گزینه «نصب برنامه» یا «افزودن به صفحه اصلی» را بزنید. در آیفون از Safari، دکمه اشتراک‌گذاری ← Add to Home Screen.

## لوگوی سازمان

لوگوی صفحه ورود و نوار بالا قابل تعویض است:

- **از داخل برنامه:** با حساب مدیر، «تنظیمات بیمه‌نامه» ← «بارگذاری لوگو» (PNG شفاف یا SVG) و «نام سازمان زیر لوگو».
- **در نسخه تک‌فایلی:** لوگو را هنگام ساخت قرار دهید تا برای همه کاربران پیش‌فرض باشد:

```bash
python3 tools/build_single.py --logo path/to/logo.png --org "شرکت ملی گاز ایران"
```

## ساختار

```
index.html              پوسته اپ موبایل
site.html               پوسته سایت (همان کد با data-mode="site")
css/app.css             سبک بصری (نوار آبی، کارت‌های خطی، کاشی‌های تصویری، برگه‌های کشویی، حالت تیره)
js/workflow.js          منطق خالص: وضعیت‌ها، انتقال‌ها، مدارک لازم، اعتبارسنجی، تاریخ شمسی، محاسبه خسارت
js/store.js             ذخیره‌سازی محلی، فایل‌ها، اعلان، پیامک شبیه‌سازی‌شده و داده نمونه
js/icons.js             آیکون‌های خطی و تصویرسازی کاشی‌ها (دست‌ساز، SVG)
js/app.js               رابط کاربری همه نقش‌ها
sw.js, manifest.webmanifest   نصب و کار آفلاین
tests/workflow.test.mjs       تست‌های گردش کار
docs/DESIGN.md                سند طراحی
```

## تست

```bash
npm test
```

تست‌ها کد ملی، شبا، تبدیل تاریخ شمسی، شرط ارسال، چرخه کامل پرونده (نقص، اصلاح، استعلام بیمه‌گر، ارزیابی، پرداخت)، فرانشیز و سقف، و فهرست مدارک لازم را بررسی می‌کنند.
